## DESCAN-18K — разрешённое использование

Только **измерение референсных спектров дефектов** из `Valid.zip`/`Test.zip` для калибровки симулятора (задача 1.5). `Train.zip` (35 ГБ) не распаковывать. Не использовать в обучающих/валидационных выборках модели.

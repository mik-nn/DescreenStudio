# Descan Evaluation — правила работы

## Два режима оценки

**На синтетике (есть точный GT):** PSNR, SSIM, LPIPS. Критерий приёмки этапа 2: PSNR > 34 dB, SSIM > 0.95 на отложенной синтетической валидации.

**На реальных сканах (нет GT):** метрика остаточных периодических пиков — энергия пиков в 2D FFT после детекции σ-thresholding (алгоритм автодетектора из DSP v3.7). Сравнение: отношение энергии пиков выхода к входу, в dB.

## Baseline

- DSP v3.7 (`descreening_studio_pro.html`) — обязательная планка. Любой отчёт о качестве нейросети содержит сравнение с ней на одних и тех же реальных сканах.
- Критический тестовый режим: 150 LPI @ 300 DPI (период 2 px) — классические методы здесь слабее всего.

## Калибровка симулятора по референсам (задача 1.5)

- Референсы: сканы из `Data/Valid.zip` (DESCAN-18K, только измерение — не обучение) + собственные сканы, когда появятся.
- Измеряем: частоты пиков растра (→ LPI), углы, оценку dot gain, спектр шума сканера.
- Результат — таблица в `knowledge/reference-spectra.md`; параметры симулятора подгоняются под неё.

## Отчётность

Любой прогон оценки → запись в `JOURNAL.md`: дата, модель/чекпоинт, набор данных, метрики, вывод. Отрицательные результаты фиксируются тоже.
